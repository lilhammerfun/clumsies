# 原生文件导航器：分级验收

本版用 NSOutlineView 管理文件树的选择、展开和键盘导航，保留现有文档标签、草稿、评审及同步能力。
范围包含关闭后重新打开、展开状态保留、搜索恢复、完整目录操作、“新建文件”、拖动移动和重启恢复文档标签。
空文件夹创建正在补齐同步数据模型；临时预览标签不属于本次范围。

## 准备

- 使用 **Clumsies Dev 0be2a6e494df**，进入 **文件导航器测试 → 记忆**。
- **文件导航器对照项目**选用了同一组已发布文件，可用于验证项目草稿隔离。
- 以下按顺序执行。前三个等级均为本次必须验收的操作；每一项都列出预期结果。

## 一级：基本交互（约 3 分钟）

1. 点击“入门”左侧箭头，展开后单击“欢迎.md”。正文和一个文档标签出现。
2. 关闭该标签，立即再单击仍然选中的“欢迎.md”；重复三次。每次均能打开，同一文件不重复建标签。
3. 分别打开“欢迎.md”和“团队介绍.md”，关闭当前标签、再关闭最后一个标签。剩余标签正常接替；全部关闭后显示空白提示。
4. 单击目录名称只选中目录；点击箭头或双击目录展开/折叠。用左右方向键也可展开/折叠。
5. 在文件树用上下键选择文件，按 ⌘↓ 打开；按 Return 弹出重命名，取消后路径不变。

## 二级：组合操作（约 5 分钟）

1. 展开“手册/发布”，折叠“保留目录”。切换文档、新建一个文件、重新载入后，“保留目录”仍保持折叠。
2. 按 ⌘N 或在树的空白处右键选择“新建文件”。新文件自动在源码模式打开，输入文字、关闭、重开，文字保留。
3. 用 ⌘ 单击选择两个文件，再用 Shift 选择连续范围。多选不连续打开标签；右键菜单针对选中的集合。
4. 搜索“命中文件”，再搜索一个不存在的名称，最后清空搜索。搜索前的目录展开状态恢复。
5. 保持搜索“命中文件”，右键“目录操作”并重命名为“目录操作已改名”。清空搜索，确认“命中文件.md”和未命中的“其他文件.md”都在新目录中。
6. 在源码中输入一行新文字，立即从文件树重命名该文件。关闭再打开，路径和新文字都保留；尝试同名、空名称、斜杠时不得覆盖其他文件。
7. 将文件拖入另一个目录，再通过右键“移动到 → 根目录”移出；再多选目录及其子文件一起移动。相对路径和正文保留，子文件只移动一次；目标同名、自身或子目录均不能接受拖放。

## 三级：业务与生命周期（约 5 分钟）

1. 在测试项目中修改“入门/欢迎.md”，切到对照项目打开同一文件。对照项目仍显示已发布版本；切回测试项目仍显示自己的草稿。
2. 在两个项目中设置不同的目录展开状态，来回切换，再退出并重新启动这个 Dev App。各项目的展开状态独立保留。
3. 在测试项目删除“团队介绍.md”。应显示待删除草稿，组织正式版本和对照项目仍保留文件；丢弃该草稿后恢复。
4. 对修改后的文件查看 Diff，并打开“请求评审”窗口。差异及目标文件正确；取消后编辑内容仍在。
5. 修改源码后立即退出 Dev App，再打开并重新进入该文件。已输入内容保留，无需等待远端发布。
6. 两个项目各打开多个文件，选中各自的第一个标签并切换项目。再退出重开：各项目的标签、模式和活动标签均恢复；退出前已关闭的标签不会重新出现。
