# Clumsies v0.20.6

A maintenance release for macOS repository bindings and project settings,
and Windows/Linux startup, sign-in recovery, and project refresh.

## Install and update

| Platform | Download | Notes |
| --- | --- | --- |
| macOS | `Clumsies-0.20.6-macos-arm64.dmg` | Open it and drag Clumsies.app into Applications. Requires macOS 14 or later and Apple Silicon. Existing installations can use Check for Updates. |
| Linux | `Clumsies-0.20.6-linux-x86_64.tar.gz` | Unpack and run `./clumsies-desktop`, or use `./install.sh` to add it to your launcher. Requires x86-64 and glibc. |
| Windows | `Clumsies-0.20.6-windows-x86_64-Setup.exe` | Installs for the current user without administrator permission. Requires Windows 10 version 2004 or later and x86-64. |

The Windows ZIP remains available for portable use. Close the client and active
Agent sessions before updating. The installer preserves account and Memory data
and bundles the VC++ runtime.

The desktop packages are not signed. Windows may show SmartScreen on first use.
The macOS app is ad-hoc signed and not notarized by Apple; a manual download may
require System Settings → Privacy & Security → Open Anyway. Sparkle verifies
the signed in-app update.

## Changes since v0.20.5

### macOS

- Repository removal can proceed while the binding list is refreshing. The
  confirmation retains the selected repository, and stale refresh results
  cannot restore old rows or hide an operation failure.
- Repository and cache errors appear beside their controls in project settings.
  Delete Project is the final section on the page.
- Client diagnostics record repository action intent and request outcomes with
  correlation IDs and path fingerprints, without logging raw local paths.

### Windows and Linux

- Fix Windows startup and sign-in recovery, including expired sessions during
  project refresh.
- Refresh project memberships without restarting and download uncached Memory
  when selecting a project.
- Open project settings beside the Memory picker.
- Include a per-user Windows installer alongside the portable ZIP.

## Compatibility and rollback

No API, schema, or data migration is required. Repository binding rules are
unchanged: a project can bind several local directories, while one directory
cannot belong to two projects on the same machine.

To roll back, close the client and install v0.20.5. No database restore is
required. The initial Windows/Linux feature limitations listed in v0.20.5
remain; the Windows GUI has not been verified on a physical desktop.

## Build and integrity

GitHub Actions builds and checks the macOS DMG, Linux archive, and Windows
installer and ZIP. Each package has a SHA-256 checksum. The release also
updates the stable and preview macOS update feeds.
