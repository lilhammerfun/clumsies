# Clumsies v0.20.6

The first cross-platform Rust CLI release, alongside macOS repository
binding and project settings fixes. Windows/Linux GUI development is paused;
the native macOS App remains supported.

## Install and update

| Platform | Download | Notes |
| --- | --- | --- |
| macOS | `Clumsies-0.20.6-macos-arm64.dmg` | Open it and drag Clumsies.app into Applications. Requires macOS 14 or later and Apple Silicon. Existing installations can use Check for Updates. |
| Linux CLI | `clumsies-cli-0.20.6-linux-x86_64.tar.gz` | Extract, enter the package directory, and run `./install.sh`. Add `~/.local/bin` to PATH. Tested on Ubuntu 24.04 x86-64 and compatible glibc systems. |
| Windows CLI | `clumsies-cli-0.20.6-windows-x86_64-Setup.exe` | Installs for the current user without administrator permission and adds the runtime to user PATH. Reopen terminals after installation. Requires Windows x64. |

The matching Windows ZIP supports portable use and includes `install.ps1`.
Each CLI package contains both `clumsies` and `clumsiesd`; upgrade them together.
Installation, upgrade, and uninstall preserve credentials, local drafts,
repository bindings, and caches. Close active CLI/MCP processes when Windows
reports a file in use. The Windows package bundles the required MSVC runtime.

On macOS, the App now embeds `Contents/Resources/clumsies`. It shares the App's
launch agent, Keychain, settings, and cache; standalone daemon stop/restart
remains managed through the App.

The Windows CLI installer is unsigned and may show SmartScreen on first use.
The macOS app is ad-hoc signed and not notarized by Apple; a manual download may
require System Settings → Privacy & Security → Open Anyway. Sparkle verifies
the signed in-app update.

## Changes since v0.20.5

### macOS

- Repository removal can proceed while the binding list is refreshing. The
  confirmation retains the selected repository, and stale refresh results
  cannot restore old rows or hide an operation failure.
- Repository and cache errors appear beside their controls in project settings.
  Delete Project is the final section on the page.
- Client diagnostics record repository action intent and request outcomes with
  correlation IDs and path fingerprints, without logging raw local paths.

### CLI and shared runtime

- Sign in through browser OIDC or deployment-enabled password authentication,
  select a project, bind repositories, and configure Agent integrations.
- Inspect and synchronize local drafts, create and review Memory proposals,
  comment, approve, reject, reconcile, and publish through existing Server APIs.
  Mutations use the inspected version and reference and reject stale state.
- Start and reuse the user-local daemon on Windows/Linux without a GUI or
  system service. Credentials and Memory stay owned by the shared daemon.
- Install a matching CLI/daemon pair at user level. Upgrade and uninstall are
  tested on Windows and Linux; Windows upgrades wait briefly for transient
  executable handles to release and still reject persistent file locks.
- Verify native CLI, daemon, MCP, and successful model-backed retrieval on both
  Windows and Linux in CI, including authentication failure preservation.

## Compatibility and rollback

No API, schema, or data migration is required. Repository binding rules are
unchanged: a project can bind several local directories, while one directory
cannot belong to two projects on the same machine.

The CLI uses existing Server permissions and authentication; it adds no
Server endpoint or separate credential store. First retrieval prepares the
pinned models (about 412 MiB). Headless OIDC needs the existing loopback
callback forwarded to the browser, or deployment-enabled password login.

There is no v0.20.5 package of this Rust CLI. To stop using it, uninstall its
programs; daemon data is retained. For macOS rollback, close the App and
install v0.20.5. Stop the runtime and back up its complete data root before
downgrading; installers do not provide automatic database schema downgrades.

## Build and integrity

GitHub Actions builds and checks the macOS DMG, Linux CLI archive, and Windows
CLI installer and ZIP. Each package has a SHA-256 checksum; CLI archives also
include an internal `SHA256SUMS` manifest. The release also
updates the stable and preview macOS update feeds.
