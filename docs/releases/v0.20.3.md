# Clumsies v0.20.3

A macOS performance release since v0.20.2.

## Install and update

Download `Clumsies-0.20.3-macos-arm64.dmg`, open it, and drag Clumsies.app into Applications. Requires macOS 14 or later and Apple Silicon (M1 or newer). Existing installations can use Settings → General → Check for Updates. Accounts, local Memory, repository bindings, and settings are retained.

The app and bundled daemon are ad-hoc signed and are not notarized by Apple. A manual download may require System Settings → Privacy & Security → Open Anyway.

## Changes since v0.20.2

- Reuse a healthy local service whose build identity matches the installed app, removing the repeated full daemon hash from warm startup.
- Open the workspace while Agent integration maintenance finishes in the background.
- Start Review loading as soon as account and project identity are known, alongside Memory and workspace requests. Avoid duplicate initial refreshes and shorten independent version checks.
- Replace the timed startup message with accurate opening text and record startup phase durations for diagnosis.

## Verification and limits

On an isolated local Dev App, two warm starts improved daemon readiness from 3.84–4.37 seconds to 5–12 milliseconds and workspace snapshot readiness from 3.90–4.43 seconds to 61–145 milliseconds. These measurements use a local test server; production network and upgrade timings must be measured after distribution. The Review playground fixture failed while seeding a populated list, so that UI scenario remains unmeasured.

## Compatibility and rollback

No API, schema, or data migration is required. A missing or mismatched build identity uses the existing full service reconciliation path. To roll back, install the v0.20.2 app; no database restore is needed.

## Build and integrity

The downloadable app uses the existing Debug ad-hoc runtime contract and stable update feed. A SHA-256 checksum accompanies the DMG, and Sparkle verifies the signed update before installation.
