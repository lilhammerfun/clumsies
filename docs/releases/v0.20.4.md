# Clumsies v0.20.4

A macOS startup maintenance release since v0.20.3.

## Install and update

Download `Clumsies-0.20.4-macos-arm64.dmg`, open it, and drag Clumsies.app into Applications. Requires macOS 14 or later and Apple Silicon (M1 or newer). Existing installations can use Settings → General → Check for Updates. Accounts, local Memory, repository bindings, and settings are retained.

The app and bundled daemon are ad-hoc signed and are not notarized by Apple. A manual download may require System Settings → Privacy & Security → Open Anyway.

## Changes since v0.20.3

- Check AI tool integrations once per installed daemon build, instead of on every App launch.
- Skip disabled tools that have no installed integration or old files to clean up.
- During initial setup, write only tool settings the user changed or selected.

## Compatibility and rollback

No API, schema, or data migration is required. A failed initial settings request can be retried on the next launch; individual tool errors are reported during the upgrade check, and settings can be changed manually. To roll back, install the v0.20.3 app; no database restore is needed.

## Build and integrity

The downloadable app uses the existing Debug ad-hoc runtime contract and stable update feed. A SHA-256 checksum accompanies the DMG, and Sparkle verifies the signed update before installation.
