# Clumsies v0.20.2

A maintenance release for the macOS app and Server since v0.20.1.

## Install and update

Download `Clumsies-0.20.2-macos-arm64.dmg`, open it, and drag Clumsies.app into Applications. Requires macOS 14 or later and Apple Silicon (M1 or newer). Windows, Linux, and Intel Mac installers are not included.

Existing installations can use Settings → General → Check for Updates. The Sparkle-signed update is offered through the stable and Preview feeds; after upgrading, the app uses the stable feed. For manual installation, quit Clumsies before replacing the app. Accounts, local Memory, repository bindings, and settings are retained.

This is a normal GitHub release marked Latest. The app and bundled daemon are ad-hoc signed and are not notarized by Apple. A manual download may require System Settings → Privacy & Security → Open Anyway; managed Macs may restrict that exception.

## Changes since v0.20.1

- Show real file paths and folders in merged Review trees for ID-targeted Draft updates whose operations omit paths.
- Restore single-click selection of Review files and single-click expansion of folders.
- Allow Inbox receipts for accessible Draft conflict notifications.

## Compatibility and rollback

No schema migration or API change is required for these fixes. Update the app and Server together to include the Inbox receipt fix. Existing Review and Inbox data remain compatible. To roll back, install the v0.20.1 app and Server; no database restore is needed for this release.

## Build and integrity

The downloadable app uses the existing Debug ad-hoc runtime contract, regular app and daemon identities, and stable update feed. A SHA-256 checksum accompanies the DMG, and Sparkle verifies the signed update before installation. Developer ID signing and Apple notarization remain a separate workflow.
