# 任务指南

已经知道要完成什么时，从这里选入口。每项说明适用的起点和预期结果。第一次学习完整工作流程，请跟随[五步快速开始](/zh/quickstart/)。

## 使用和维护团队知识

| 任务 | 什么时候需要 | 完成后的结果 |
| --- | --- | --- |
| [选择已有的组织 Memory](/zh/quickstart/select-memory) | 共享文档已经存在，当前 Project 还没有使用它 | 项目引用所选 Memory |
| [让 Codex 使用所选 Memory](/zh/quickstart/use-with-agent) | 仓库已绑定 Project | Codex 检索当前任务需要的知识 |
| [让 Codex 提出修改](/zh/quickstart/update-memory) | 共享文档有一处具体内容需要修正 | Draft 中保存了授权的修改 |
| [审阅并发布提案](/zh/quickstart/review-and-publish) | Draft 已准备好交给人审阅 | 经审阅的更新成为共享版本 |
| [创建新的 Memory](/zh/guides/create-memory) | 组织中还没有需要的知识 | 新文档被提出并发布 |
| [查找常用成员任务](/zh/guides/how-to-use-clumsies) | 想直接进入熟悉的某个环节 | 找到对应步骤，不必重读整组教程 |

前四项也是教程中的环节，两处链接到同一份操作说明，避免内容更新后不一致。创建新 Memory 是补充任务；使用已有 Memory 不需要复制正文。
