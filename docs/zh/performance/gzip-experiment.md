# 跨区传输与 gzip：一次因果实验

在 Server 计算被削减之后，跨区传输变得显眼。只有当客户端声明接受该编码时，
代理 gzip 才有帮助。

## 实验

对相同的路由与请求体，分别在带与不带 `Accept-Encoding: gzip`
的情况下对比。在保持 revision、区域、凭据与请求形状不变的前提下，记录上游时间、
端到端时间、`Content-Encoding`、线上字节与解码后字节。
上游工作不变而传输表示变化，比一次无关的部署前后对比给出更强的因果证据。

gzip 不会改善 DNS、TCP、TLS 或 TTFB。小响应可能没有收益，
单个样本不是 SLO，压缩也不能替代字段选择或增量同步。只改配置不构成验收证据：
要在真实客户端边界上核对响应头与线上大小。
